# Sana Hub — AI Sana Challenge Hub

Минимальный MVP для трека HackAlem / AI Sana: от короткой бизнес-задачи к понятной карточке, каталогу и ручному выбору команды.

## Стек и архитектура

Изначально в репозитории не было frontend/backend стека, поэтому выбран статический SPA на vanilla JavaScript и ES-модулях без внешних зависимостей. Данные демо хранятся в `localStorage`; AI fallback находится в `src/services/ai.js`, а детерминированный readiness scoring — в `src/services/scoring.js`.

## Запуск

Раздайте корень репозитория локальным статическим web-сервером. Python в окружении не требуется — используйте встроенный сервер Node.js:

```bash
node server.mjs
```

Откройте `http://localhost:4173`. ES-модули требуют web-сервер, поэтому прямое открытие файла может быть ограничено браузером.

## Страницы

- `#/business/intake` — описание и AI-уточнение;
- `#/business/card` — редактируемая карточка, score breakdown, публикация;
- `#/catalog` — общий каталог с фильтрами по теме и уровню;
- `#/task/:id` — карточка задачи и форма предложения команды;
- `#/business/proposals` — ручное принятие или отклонение предложений.

Переключатель «Бизнес / Команда» заменяет авторизацию в демонстрационном сценарии.

## Модели и scoring

`Task` содержит title, context, need, users, data, constraints, expectedResult, successCriteria, businessContact, interactionFormat, score, readinessLevel и status. `Team` содержит название, интересы, навыки и технологии. `Proposal` связывает задачу и команду и хранит solutionIdea, plan, duration, prototypeUrl и статус `pending | accepted | rejected`.

Score считается только в приложении: контекст + потребность — 20; данные — 20; ожидаемый результат — 15; критерии успеха — 15; ограничения — 10; пользователи — 10; связь с бизнесом — 10. Уровни: `0–39 Draft`, `40–69 Working`, `70–89 Ready`, `90–100 Priority`.

Локальный AI fallback задаёт минимум 3 вопроса, оставляет результат редактируемым и не подставляет неподтверждённые факты. Публикация требует ручного подтверждения бизнеса; команда никогда не назначается автоматически.

## Демо-данные и сценарий

В `src/data.js` есть 5 синтетических задач, 5 команд и 5 предложений. Для демонстрации: введите слабое описание в режиме бизнеса, покажите вопросы, ответьте на них прямо в форме, сформируйте карточку, отредактируйте поля, подтвердите и опубликуйте её, переключитесь в режим команды, отправьте предложение, затем в разделе «Предложения» примите или отклоните его вручную.

Для сброса демо-данных выполните в консоли браузера `resetSanaDemo()`.
